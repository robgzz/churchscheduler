# Upgrade Westbury Church Hub V4.0.1 -> V4.1.0

1. Back up the current repository and confirm the current Azure app is healthy.
2. Replace/update the repository with this V4.1.0 source package.
3. Reconcile infrastructure once so Azure creates `ChatSessions` and `ChatUnknowns` and configures the pickup-code encryption secret:

```powershell
.\scripts\validate-infra.ps1
.\scripts\first-deploy.ps1 `
  -ResourceGroup "<existing-resource-group>" `
  -Location "<existing-location>" `
  -NamePrefix "<existing-prefix>" `
  -ChurchId "westbury" `
  -InitialOwnerUsername "<existing-owner-username>" `
  -MinReplicas 1
```

The script detects/reuses the currently running web/job images while Bicep reconciles infrastructure, then builds V4.1.0. If you manage `PICKUP_CODE_ENCRYPTION_KEY` externally, supply the same stable 32-byte base64 value on future infrastructure reconciliations.

4. Verify `/healthz` reports `4.1.0`.
5. Open Admin -> Settings -> Manage Modules and confirm **Chat Hub** is active. It can be disabled at any time without removing other Church Hub features or historical data.
6. Test as a member: `¿Qué me toca?`, announcement lookup, microphone, and (if enrolled) Children Care pickup code.
7. Test as an administrator: `Estado del programa` and `Sube el boletín de esta semana` with a PDF/JPG/PNG attachment.
8. Continue normal releases by pushing `main`; GitHub Actions runs tests and syntax checks before deploying the SHA-tagged image.

## Rollback
Rollback remains image-based using a prior Git SHA. If the V4.1 Chat Hub module itself needs to be isolated first, disable **Chat Hub** in Module Administration; the rest of Westbury Church Hub remains available.
