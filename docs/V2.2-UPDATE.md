# V2.2 Update

## UX

- Prominent service-date tiles and relative date context.
- Stronger "Your assignment" presentation for worship volunteers.
- Cantos assignments visually highlight the additional song-selection action.
- Home prioritizes the member's next responsibility before general service information.
- Program cards use clearer date/service hierarchy.
- Navigation receives friendlier mobile icons while retaining bilingual labels.

## Cantos picker

The picker no longer requires scrolling through the hymn library to reach Save. It is a fixed four-part layout:

1. Assignment/service header.
2. Search + All/Selected filters.
3. Independently scrolling song list.
4. Persistent selected-count + Cancel/Save action area.

Selecting a row updates the count immediately. The selected-only filter makes it easy to review or remove choices before saving.

## Performance

V2.2 adds read-through cache TTLs for low-churn Azure Table data:

- Church settings: 5 minutes
- Services: 5 minutes
- Ministries: 5 minutes
- Program templates: 5 minutes
- Songs: 10 minutes
- Member profiles: 1 minute

Any create/update/delete to one of those tables invalidates that table's in-process cache for the church. Dynamic Programs, Assignments, History, Petitions and Visitor data are not server-cached.

The member browser also caches Programs/Assignments for 30 seconds to avoid duplicate reads while switching between Home and Schedule. Assignment-changing actions invalidate the client cache immediately.

HTTP compression and an updated PWA service-worker strategy reduce transfer and repeat-load cost.

## Scale

The infrastructure default `maxReplicas` is now 4 while `minReplicas` stays at 0. This preserves the low-cost Consumption model but leaves more burst headroom around service times. Existing deployments only receive Bicep infrastructure defaults when Bicep is reconciled; the app-level caching/compression improvements deploy normally through GitHub Actions.

## Communications

Azure Communication Services SMS/email is not provisioned in this release.
