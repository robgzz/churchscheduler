# Upgrade to Westbury Church Hub V5.6.0

V5.6 is an application-only release. It does not add Azure resources or change the Westbury bootstrap process.

## Normal deployment

Use the existing GitHub deployment flow:

1. Replace the repository application files with the V5.6 full package while preserving `.git` and your repository settings.
2. Commit the V5.6 changes.
3. Push `main`.
4. Allow the existing GitHub Actions workflow to test, build and deploy the web app/job.
5. Close and reopen the PWA/browser once so the V5.6 shell cache is loaded.

Do not rerun first-time church setup merely to install this release.

## Suggested Chat Hub regression conversation

After deployment, test a multi-domain sequence rather than isolated phrases:

- `¿Quién falta escoger cantos?`
- `¿Cuáles son mis cantos?`
- `¿Qué asignaciones tengo?`
- `¿Ya están elegidos mis cantos?`
- start the responsible-administrator procedure
- before completing it ask `¿Qué tareas tengo?`
- then ask `Dime los cantos que escogí.`
- ask `¿Quién estuvo encargado de la Cena el domingo pasado?`

The important V5.6 behavior is that each explicit new goal is interpreted on its own merits and is not swallowed by the unfinished administrator workflow.
