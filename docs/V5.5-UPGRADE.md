# Upgrade to V5.5.0

V5.5.0 is an application-only release. No new Azure resources, storage tables, or Bicep reconciliation are required.

Deploy through the normal GitHub `main` workflow. After deployment, close and reopen the PWA/browser once so the v550 static cache is loaded.

Recommended checks:
1. Ask `¿Cómo escojo cantos?`.
2. Ask `Escoger cantos para domingo 27 de septiembre`.
3. During that flow reply `Cantos` or `Elige cantos` and verify context is preserved.
4. Ask `¿Cómo marco un administrador como administrador responsable?`.
5. Use `Hazlo por mí`, choose an administrator, confirm, and verify the setting changed.
