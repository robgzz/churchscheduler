# Church Scheduler V2.1 Update

This release is an application update. It does **not** require new Azure infrastructure or a Bicep redeployment when upgrading an already working V2 deployment through GitHub Actions.

## Included changes

1. **Complete English / Spanish experience**
   - Member, visitor, worship, and Admin screens use the same bilingual translation layer.
   - A visible `ES / EN` switch is available in the header.
   - Member language preference is stored in Azure Table Storage and also cached locally.
   - Services, ministries, program lines, news, bulletins, songs, forms, history labels, and common API errors support bilingual display/fallbacks.

2. **Light / Dark theme control**
   - Header button switches immediately between light and dark.
   - Profile includes System / Light / Dark options.
   - Theme preference is stored for signed-in members.

3. **Cantos song selection**
   - A worship member assigned to the canonical `ministry_songs` assignment gets Select/Edit Songs.
   - Multiple hymns can be selected from the full church song library.
   - Selections are stored on that specific assignment and appear in program views immediately.
   - Reassigning a Cantos assignment clears the previous volunteer's song selection to avoid stale ownership.

4. **Data-driven church branding**
   - Westbury is seeded with the supplied Westbury Church of Christ logo.
   - Admin > Settings > Church Profile allows church name, logo, and accent color changes.
   - Uploaded logos are stored in Azure Blob Storage and served through the app.
   - The home page, sign-in screen, and headers use the configured church profile rather than a hard-coded WP mark.

5. **Program sharing**
   - Any signed-in member can view the three-week program.
   - Each program has Native Share, WhatsApp, and Text/SMS share actions.
   - Shared text includes service, date/time, program roles, names, and selected songs.

## Existing-data migration

The seed schema is now version 4. On first V2.1 startup, existing V2 Azure data is upgraded in place with missing bilingual labels and preferences. Existing members, accounts, assignments, history, songs, and schedules are not deleted.

## Deploy from the existing GitHub repository

Copy the contents of this release over your existing `churchscheduler` working folder (keep the existing `.git` folder), then use GitHub Desktop:

1. Review Changes.
2. Commit with a message such as `Church Scheduler V2.1 bilingual songs branding sharing`.
3. Push origin.
4. GitHub Actions builds the image and updates Azure Container Apps automatically.

No Bicep redeploy is required for this release.

## SMS/email note

V2.1 does not enable automated Azure Communication Services SMS or email notifications. The Text button is user-initiated program sharing through the mobile device's messaging app. Automated SMS/email can be added as a later Azure Communication Services integration.
