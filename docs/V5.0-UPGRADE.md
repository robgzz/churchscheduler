# V5.0 Upgrade

V5.0.0 is an application-only upgrade from V4.6.0.

1. Replace the repository working tree with the V5.0.0 full package while preserving `.git` and environment secrets.
2. Commit and push to `main`.
3. Let GitHub Actions build and deploy the application image.
4. Close/reopen installed PWAs or browser tabs once after deployment so the V5 cache key is used.
5. Validate `/healthz` reports `5.0.0`.
6. Validate the Administrator Console and Chat Hub.

No new Azure tables, resources, bootstrap operation, or infrastructure reconciliation is required.
