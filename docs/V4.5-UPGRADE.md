# V4.5 Upgrade

V4.5.0 is an application-only upgrade from V4.4.0. It does not require new Azure resources, tables, or bootstrap.

1. Replace the repository application files with the V4.5.0 package while preserving `.git`.
2. Commit and push `main`.
3. Let GitHub Actions build and deploy the V4.5.0 container image.
4. Close and reopen the PWA/browser once so the V4.5 cache version is active.
5. Validate Admin Console, Chat Hub > Open People, password change, and Wednesday-class queries.
