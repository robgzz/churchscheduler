# Upgrade to Westbury Church Hub V4.3.0

## Existing V4.1/V4.2 Azure installation
No new Azure resource is required.

1. Back up or retain the current known-good Git commit.
2. Replace/update the repository contents with the V4.3.0 full package while preserving your repository `.git` directory and configured GitHub secrets.
3. Commit the V4.3.0 changes to `main`.
4. Push `main`.
5. Let GitHub Actions run tests, syntax validation, container build/push, Container App update, scheduler job update, and health check.
6. Hard-refresh/reopen the installed PWA after deployment. V4.3 changes the shell cache key and asset query versions to force updated browser assets.

Do not rerun bootstrap for an already initialized church.

## Post-deployment checks
- Sign in as the Church Administrator and open Administration.
- Verify the admin dashboard loads.
- Verify bottom navigation scrolls horizontally on a narrow phone.
- Verify Chat Hub recognizes: `Crear una cuenta de miembro`, `¿Qué peticiones hay?`, `Crea una petición`, `¿Quién va a predicar este domingo?`, and `¿Cuántos anuncios hay hoy?`.
- Verify Children Care offers one-time parent verification and caregiver photo-ID fallback.
- Verify expired prayer requests disappear from current/public lists after fourteen days.
