# V4.6 Upgrade

V4.6.0 is an application-only upgrade from V4.5.0. No new Azure resources, bootstrap, or first-deploy run is required.

1. Replace repository application files with this package while preserving `.git`.
2. Commit and push `main`.
3. Let GitHub Actions deploy V4.6.0.
4. Close/reopen installed PWAs/browser tabs once so V4.6 cache keys are used.
5. Validate `/healthz` reports `4.6.0`, then open `/admin/?tab=people`.
