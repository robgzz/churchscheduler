# Westbury Church Hub V6.1.0 Upgrade

## Normal upgrade

No infrastructure bootstrap is required.

1. Preserve the repository `.git` directory.
2. Replace the working tree with the V6.1.0 full package.
3. Commit and push `main`.
4. GitHub Actions builds and deploys the new revision.
5. Close/reopen the PWA/browser once so the V6.1 service-worker cache is loaded.

## ACS email

The GitHub workflow now discovers the existing `westburyapp-acs` resource and restores the ACS endpoint, sender, and email enablement on both the web app and scheduler job.

After deployment, open **Administración → Configuración → Comunicaciones**. Email should show:

- sender: `WestburyChurchofChrist@exonuvia.com`
- service: enabled

Then send an Email test to a member with a valid email address.

If the app is configured but Azure returns a 401/403, verify that the Container App managed identity still has the required ACS role assignment. Do not add a connection string or shared key as a workaround.

## Member participation workbook

The full package includes `imports/Westbury-Members-Participation-Corrected.xlsx`. Importing it in exact-state mode replaces member ministry/service participation with the approved matrix without resetting existing passwords.
