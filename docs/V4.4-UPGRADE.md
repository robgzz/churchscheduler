# Upgrade to Westbury Church Hub V4.4.0

V4.4 is an application-only upgrade from V4.3. It does not add Azure resources or tables.

1. Keep the existing repository `.git` directory and GitHub secrets.
2. Replace the repository contents with the V4.4 full package.
3. Commit and push `main`.
4. Let GitHub Actions run tests, syntax checks, build/push the container, update the web Container App and scheduler job, and perform the health check.
5. On iPhone/PWA, fully close the app/browser tab and reopen it once after deployment. V4.4 changes the service-worker cache key and versions the JavaScript module graph.
6. Confirm `/healthz` reports `4.4.0`.
7. Validate Administrator Console, horizontal bottom navigation, Church News, task/event expiry behavior, prayer deletion, and Chat Hub.

No bootstrap and no `first-deploy.ps1` run are required for an existing V4.3 deployment.
