# Upgrade to Westbury Church Hub V5.3.0

No Azure infrastructure changes are required.

1. Replace the application files with V5.3.0 while preserving the repository `.git` directory.
2. Commit and push `main`.
3. Allow GitHub Actions to run tests, build the image and deploy to Azure Container Apps.
4. Close/reopen the browser or PWA once so cache `v530` is loaded.
5. In Admin > People, open a member and review the new **Ministry eligibility by service** section.

Existing explicit assignment eligibility is preserved. Legacy global ministry/service settings are translated into the service-aware view when a profile is opened; after saving, the profile uses authoritative `assignmentEligibilityMode=explicit`.
