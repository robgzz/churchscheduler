# Upgrade to V5.2.0

No Azure infrastructure reconciliation or bootstrap is required.

1. Replace the application files with V5.2.0 while preserving `.git`.
2. Commit and push `main`.
3. Let GitHub Actions run tests, build the image, and deploy the web app/job.
4. Close/reopen the browser or PWA once so the V5.2 static cache is loaded.
5. Open **Administration → People → Import members and service assignments**.
6. Upload `imports/Westbury-Members-Final-Upload.xlsx` (or the final workbook supplied separately).

The import is owner-only. Existing passwords are never reset. New accounts receive deterministic usernames and initial password `welcome`, with forced password change on first sign-in.

`Admin=Yes` grants Admin Console access. The existing Church Administrator is preserved and cannot be transferred by spreadsheet.
