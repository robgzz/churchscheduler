# V4.0 GitHub upgrade

1. Download and extract the full V4.0 ZIP.
2. Back up the current GitHub repository and Azure data.
3. Copy the extracted contents into the existing repository root, preserving `.git` and configured GitHub secrets.
4. Review the diff, commit `Release Westbury Church Hub v4.0.0`, and push `main`.
5. Confirm GitHub Actions completes tests, syntax validation, OIDC login, Docker build/push, web deployment, job deployment, and health check.
6. Open `/healthz` and confirm version `4.0.0`.
7. As Church Administrator, open Settings → Manage Modules. Enable Events or Follow-up only when ready.
8. Test child check-in, pickup request, caregiver verification, event RSVP, report export, and module disable/re-enable before general rollout.

Rollback by reverting to the prior known-good Git commit and allowing the normal workflow to deploy it. V4 storage changes are additive; do not delete tables during rollback.
